# API Reference 🔌

This document provides a comprehensive technical reference for all endpoints exposed by the **FallenWiki Crawler** FastAPI backend.

---

## 1. Route Summary

| Endpoint | Method | Content-Type | Purpose |
|---|---|---|---|
| `/` | `GET` | `text/html` | Serves the single-page application interface (`index.html`). |
| `/logo.png` | `GET` | `image/png` | Serves the brand logo / author avatar image. |
| `/stream` | `POST` | `multipart/form-data` → `text/event-stream` | Initiates crawling and streams real-time SSE progress events. |
| `/control` | `POST` | `application/json` → `application/json` | Sends control commands (`pause`, `resume`, `stop`) to an active crawl. |
| `/download-result/{job_id}` | `GET` | `text/markdown` or `text/plain` | Downloads the generated file and deletes temporary scratch storage. |

---

## 2. Detailed Endpoint Specifications

### 2.1. Serve Web UI — `GET /`

Returns the primary HTML/CSS/JavaScript single-page application.

- **Request**: No parameters.
- **Response**: `200 OK` (`text/html; charset=utf-8`)

---

### 2.2. Serve Brand Asset — `GET /logo.png`

Returns the application brand avatar (`logo.png`).

- **Request**: No parameters.
- **Response**: `200 OK` (`image/png`)

---

### 2.3. Initiate Crawl Stream — `POST /stream`

Starts a crawling job asynchronously and returns an open Server-Sent Events (`text/event-stream`) connection.

#### Request Parameters (`multipart/form-data`)

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `job_id` | `string` | **Yes** | — | Unique identifier generated by the client (e.g. UUIDv4 or timestamp). |
| `mode` | `string` | No | `"links"` | `"all_pages"` (discover all via API) or `"links"` (crawl specific URLs). |
| `url` | `string` | Conditional | `None` | Wiki Base URL (for `all_pages`) or Single Target URL (for `links`). |
| `file` | `UploadFile` | Conditional | `None` | Text file containing target URLs (one per line) for `links` mode. |
| `filename`| `string` | No | `None` | Custom export filename (extension automatically added). |
| `format` | `string` | No | `"txt"` | Output format: `"txt"` (Plain Text) or `"md"` (Markdown). |
| `sleep` | `float` | No | `1.0` | Politeness delay between page requests in seconds (Clamped between `0.5` and `10.0`). |

#### SSE Event Payload Schema

```json
{
  "type": "info | processing | success | error | stopped | complete",
  "message": "Human readable status string",
  "folder": "fandom_data_12345678" // Only present in 'complete' or 'stopped'
}
```

---

### 2.4. Job Control — `POST /control`

Transmits command signals to pause, resume, or abort an in-flight crawl.

#### Request Body (`application/json`)

```json
{
  "job_id": "job-unique-id",
  "action": "pause" // "pause" | "resume" | "stop"
}
```

---

### 2.5. Download Export File — `GET /download-result/{job_id}`

Retrieves the compiled Markdown or Text export file and disposes of the server scratch directory.

#### Response Headers
```http
HTTP/1.1 200 OK
Content-Type: text/markdown; charset=utf-8
Content-Disposition: attachment; filename="Custom_Export.md"
```
